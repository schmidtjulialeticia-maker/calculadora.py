# Projetos Python

Projetos desenvolvidos para praticar programação em Python.

## Calculadora

Calculadora com interface gráfica criada usando Python e Tkinter.

Funcionalidades:
- Soma
- Subtração
- Multiplicação
- Divisão


## Gerador de Senhas

Aplicação que cria senhas aleatórias com uma interface gráfica.

Funcionalidades:
- Escolha do tamanho da senha
- Geração de letras, números e símbolos


## Tecnologias utilizadas

- Python
- Tkinter
